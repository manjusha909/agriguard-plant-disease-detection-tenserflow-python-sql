# Plant Disease Detection System

This project is a Plant Disease Detection system developed to identify diseases in plants using images of leaves.  
The goal of this project is to help in early detection of plant diseases using technology.

---

## Project Description
The system allows users to upload an image of a plant leaf and predicts whether the plant is healthy or affected by a disease.  
It reduces manual checking and provides quick results.

---

## Features
- Upload plant leaf image
- Detect plant disease
- Simple and easy-to-use interface
- Fast prediction
